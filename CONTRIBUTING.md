# Contributing

Thanks for helping. This repository is one part of the [Zuujis free game assets](https://github.com/zuujiscom/free-game-assets);
the rules, the checks and how to offer new assets are in its [CONTRIBUTING.md](https://github.com/zuujiscom/free-game-assets/blob/main/CONTRIBUTING.md).

- A fix to a file here (damaged, wrong, badly named): open a pull request on this repository.
- New assets: start with an [issue on free-game-assets](https://github.com/zuujiscom/free-game-assets/issues/new?template=new-assets.yml).
- Everything here is CC0; by contributing you dedicate your contribution to the public domain under CC0 1.0.

Please follow the [code of conduct](CODE_OF_CONDUCT.md). Questions: [SUPPORT.md](SUPPORT.md).
