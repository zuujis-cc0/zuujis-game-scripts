# Planes (shared library: models/planes/)

Aircraft any game may load from `/assets/models/planes/` (Open Skies is the first). Licences: the 20 jets generated by
`resources/game-art/open-skies/build_jets.py` (asset.generator "Open Skies build_jets.py") are our own, CC0. The four
imported textured models (a320, c208b, f16 `F16.glb`, spitfire `mkvii.glb`, generator glTF-Transform) came in with the
Laravel site with **no recorded source or licence**: use them on games.zuujis.com only, and replace them before any
other site uses them.

## Open Skies — modular planes

Same convention as City Rush cars. Each entry in `manifest.json` names a folder here;
each folder holds a `plane.json` and (optionally) a `.glb` model. Adding a plane never
requires touching the game HTML.

```
manifest.json              { "planes": ["p51", "c172"] }
p51/plane.json             stats and/or model config (key = aircraft id, permanent)
p51/mustang.glb            optional 3D model
```

## plane.json

Both blocks are optional — use either or both:

```jsonc
{
  "key": "p51",

  // Registers a new aircraft (or overrides a built-in with the same key) via
  // GameFlight.register(). Physics derives stall/climb/ceiling from these REAL
  // numbers — get them from the aircraft's published specs.
  // Required: massKg, wingAreaM2, spanM, lengthM, and powerW (prop) or thrustN (jet).
  // Optional (with defaults): type 'prop'|'jet', icon, color, accent, propEff,
  //   abThrustN, spoolTau, cd0, clMax, alpha0, oswald,
  //   flaps{clBonus,cdPenalty}, gear{retractable,cd,height},
  //   rates{roll,pitch,yaw}, limits{vneKt,machMax,gMax},
  //   real{engine,maxSpeedKt,cruiseKt,stallKt,ceilingFt,climbFpm,rangeNm,year} (menu display)
  "aircraft": { ... },

  // Attaches a GLB. Without this block the game builds a procedural low-poly mesh.
  "model": {
    "glb": "mustang.glb",
    "rotateY": 0,            // degrees, if the model's nose isn't -Z
    "scaleBy": "span",       // "span" (default, x-size -> spanM) or "length" (z -> lengthM)
    "scale": null,           // explicit scale factor, overrides scaleBy
    "offsetY": 0,            // metres, fine-tune ride height
    "doubleSide": false,
    "propNodes": ["prop"],          // node-name keywords spun with the engine
    "gearNodes": ["gear", "wheel"], // node-name keywords hidden when gear is up
    "propAxis": "z"                 // local rotation axis for prop nodes
  }
}
```

Notes:
- Models auto-scale to the aircraft's real wingspan and are grounded so the wheels sit
  `gear.height` below the origin (where the physics puts ground contact).
- The procedural mesh shows instantly and hot-swaps to the GLB once loaded.
- Jets with `abThrustN` get an afterburner glow cone added automatically.
- The `key` is permanent — it's stored in score metadata.
