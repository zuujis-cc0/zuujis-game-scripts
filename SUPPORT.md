# Getting help

- **How do I use a file or pack?** Start with the [README](README.md): every pack has previews, a ZIP and a link to
  each file. The game starters explain themselves in [zuujis-game-scripts](https://github.com/zuujiscom/zuujis-game-scripts#readme).
- **Something is broken or looks wrong**: [report a problem](https://github.com/zuujiscom/free-game-assets/issues/new?template=problem.yml).
- **Questions and ideas**: [open an issue](https://github.com/zuujiscom/free-game-assets/issues/new/choose); we
  label questions `question`.
- **Want to add assets?** Read [CONTRIBUTING.md](CONTRIBUTING.md).
- **A conduct problem or anything private**: the form at <https://games.zuujis.com/report>.
- **A security problem**: see [SECURITY.md](SECURITY.md).

This is a small project run in spare time; we aim to answer within a week.
